### 3. [Unbox AI — Human-AI Collaboration Platform](./Nadavi-Chat-Bot)
*An interactive AI writing studio exploring how transparency and user control shape human-AI teamwork.*

Built for academic user studies at **miLab**, this platform pairs participants with a live AI assistant to co-write a cover letter while researchers dynamically test how people react when they can see — or control — the AI's personality sliders.

- **3 Experimental Conditions:** Tests **0% visibility (hidden)**, **read-only transparency (locked)**, and **100% user-controlled** AI behavior across Verbosity, Tone, and Self-Promotion.
- **100% Automated Telemetry:** Captures real-time interaction metrics (prompts sent, typing volume, slider adjustments, and timing) directly to cloud spreadsheets with zero manual data entry.
- **Bilingual Experience:** Full native support for both **English and Hebrew (RTL)** participants.

👉 **[Try the Live App](https://unbox-ai.vercel.app)** · **[Explore Project](./Nadavi-Chat-Bot)**
