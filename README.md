### 2️⃣ Real-Time IoT Sensor Monitoring Dashboard
**Challenge:** Create a wireless monitoring system for motion tracking without external infrastructure  
**Solution:** Developed standalone ESP32 platform with embedded web server and WebSocket streaming

![Sensor Dashboard](sensor-dashboard.png)  
*[📹 See Live Data Streaming](sensor-monitoring-demo.mp4)*

**Impact & Technical Achievement:**
- ✅ Streamed **6-axis IMU data at 100Hz** via WebSocket for real-time visualization
- ✅ Built **captive portal** enabling zero-configuration device connectivity
- ✅ Embedded **HTML/CSS/JS web interface** directly in ESP32 flash (no external hosting)
- ✅ Integrated **Hall effect sensors** for precision event counting in motion tracking

**Tech Stack:** `ESP32` `WebSocket` `Wi-Fi` `MPU6050 IMU` `I²C` `Embedded Web Server`

### 3️⃣ Multi-Axis Servo Automation System
**Challenge:** Synchronize multiple servos with WiFi control for automated positioning  
**Solution:** Designed I²C-based servo controller with web interface and animation sequencing

**Impact & Technical Achievement:**
